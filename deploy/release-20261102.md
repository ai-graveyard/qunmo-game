## 再次发布

在当前项目目录执行：

```sh
npm test
npm run build
npx wrangler@4.156.0 deploy --config wrangler.jsonc
```

需要本机已经登录 Cloudflare。账号信息与凭证不写入项目。

若需要在本机验证同样的路径路由：

```sh
npm run build
npx wrangler@4.156.0 dev --local --port 8787 --infer-origin-from-routes false
```

打开 http://127.0.0.1:8787/qunmo/ 。`--infer-origin-from-routes false` 用于保留本地 origin，避免本地代理将正式域名的 HTTPS 规范化重写为循环跳转。
